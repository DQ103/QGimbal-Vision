# K230 07 LAB-Laser Port

This branch ports the behavior of `07_7_10_laser_2025E.py` to the Radxa A7A
camera and web-preview runtime.

The original K230 source is preserved unchanged at:

`references/k230/07_7_10_laser_2025E.py`

Runtime mapping:

- Rectangle detection uses the same three progressively looser Canny passes.
- Target selection keeps the area, image-center, and previous-position weights.
- Target misses are held for three frames.
- Aim-ready uses the original tight four-pixel K230 tolerance, scaled to 540p.
- Laser candidates must match the strict 405 nm LAB violet threshold.
- A bright core with minimum luma 150 is still required.
- Laser misses are held for three frames.

## IMX415 laser calibration

The original K230 LAB threshold rejected the A7A image because its upper `b`
limit mapped to 44, while the measured IMX415/AWISP violet halo is typically
between 66 and 108.

The A7A profile therefore combines:

- Blue-channel dominance: `B-R >= 30` and `B-G >= 30`.
- OpenCV HSV hue 112-165, saturation at least 60, value at least 175.
- OpenCV LAB `a >= 150` and `b <= 112` as supporting evidence.
- A minimum violet-halo area scaled from four pixels at 400x240.
- A dynamic bright-core threshold, normally `max_luma - 8`.

Laser detection may run before aim-ready for preview and diagnostics. The
control stage still remains in target alignment until the strict aim gate is
satisfied.

Run on the A7A:

```bash
./scripts/run_a7a_imx415_k230_07_web.sh
```
