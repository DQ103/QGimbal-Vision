# K230 07 LAB-Laser Port

This branch ports the behavior of `07_7_10_laser_2025E.py` to the Radxa A7A
camera and web-preview runtime.

The original K230 source is preserved unchanged at:

`references/k230/07_7_10_laser_2025E.py`

Runtime mapping:

- Rectangle detection uses the same three progressively looser Canny passes.
- Target selection keeps the area, image-center, and previous-position weights.
- Target misses are held for three frames.
- Aim-ready uses the original tight four-pixel K230 tolerance, scaled to 540p.
- Laser candidates must match the strict 405 nm LAB violet threshold.
- A bright core with minimum luma 150 is still required.
- Laser misses are held for three frames.

Run on the A7A:

```bash
./scripts/run_a7a_imx415_k230_07_web.sh
```
