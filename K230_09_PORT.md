# K230 09 Bright-Laser Port

This branch ports the behavior of `09_7_10_2025E.py` to the Radxa A7A camera
and web-preview runtime.

The original K230 source is preserved unchanged at:

`references/k230/09_7_10_2025E.py`

Runtime mapping:

- K230 400x240 processing constants are scaled by the OpenCV implementation.
- Rectangle detection uses the same three progressively looser Canny passes.
- Target selection keeps the area, image-center, and previous-position weights.
- Target misses are held for three frames.
- Laser detection uses a dynamic grayscale threshold with minimum luma 165.
- Laser position smoothing uses alpha 0.75 and holds two missed frames.
- Laser detection is enabled only after the target enters the aim radius.

Run on the A7A:

```bash
./scripts/run_a7a_imx415_k230_09_web.sh
```
